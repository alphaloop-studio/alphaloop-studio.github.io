# EMBERCROWN: THE CINDER OATH — Art Pass 0.2

Babylon.js 기반 모바일 우선 아이소메트릭 판타지 액션 수직 슬라이스입니다.

## 핵심 방향

- 실제 리깅·애니메이션 GLB 기사와 해골 전사 보스
- 불씨 왕관 파편이라는 고유 실루엣
- 재·황동·이끼·불씨로 제한한 색채 체계
- 직교 아이소메트릭 디오라마
- 모델 로딩 실패 시 내장 수제 미니어처로 자동 폴백
