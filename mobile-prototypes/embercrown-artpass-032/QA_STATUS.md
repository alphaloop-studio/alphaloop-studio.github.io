# EMBERCROWN Art Pass 0.3.2 — 조작·진행 핫픽스

## 수정 완료

- WASD·방향키와 모바일 조이스틱을 월드 축이 아닌 카메라 화면 축에 맞춰 변환합니다.
- W/조이스틱 위는 화면 위, S/아래는 화면 아래, A·D는 화면 좌우로 이동합니다.
- 첫 망령 4명은 맹세석 활성화 이후에만 생성됩니다.
- 맹세석 이전 선제 처치로 퀘스트가 정지하던 경로를 제거했습니다.
- 각 처치 뒤 남은 망령 수를 다시 계산하고 0명이 되면 자동으로 길불 단계로 전환합니다.
- 모바일 버튼 명칭을 `대화`에서 `상호작용`으로 정리했습니다.

## 자동 검증

- 직접 수정 소스 조작·진행 검사: 15 / 15 PASS
- 공개 런타임 패치 로더 통합 검사: 11 / 11 PASS
- W/S/A/D 화면 기준 방향 검사
- 실제 터치 드래그 조이스틱 상향 검사
- 실제 상호작용 버튼으로 맹세석 → 망령 4명 → 길불 3개 → 보스 → 승리 검사
- 콘솔 오류 0, 페이지 예외 0

## 배포 구조

- 새 경로는 기존 0.3.1의 6개 검증 payload를 불러옵니다.
- 기반 HTML SHA-256을 확인한 뒤 11개 변경 블록을 정확히 한 번씩 적용합니다.
- 완성된 0.3.2 HTML의 SHA-256이 `10784ec8783d0c604e40b3bbf3f61ef9e95dfc4a1c7c7d6ba601f6ddbb30b441`인지 다시 확인한 뒤 실행합니다.
- 기반 시그니처나 결과 해시가 다르면 게임을 실행하지 않고 오류 화면을 표시합니다.

## 제한

- Browser 플러그인은 제공되지 않아 Python Playwright와 시스템 Chromium을 사용했습니다.
- Babylon API QA 스텁으로 로더, 입력과 상태 전이를 검증했습니다.
- 외부 브라우저/DNS가 차단된 환경이어서 실제 CDN·GLB·WebGL 렌더링과 iPhone 실기기 성능은 이 검사에 포함되지 않았습니다.
